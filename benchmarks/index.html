What each layer costs, measured

Every piece Open Inference Fabric adds to an inference stack, from a GPU fraction to the Dynamo frontend, gets the same test: does it change what the GPU delivers? Each report names its hardware, versions and repeats, and links the data and scripts to rerun it.

AMD GPU fractions in KAI: a hard memory cap at no performance cost

An AMD backend for KAI gpu-fractioning caps each fractional pod's GPU memory with the Linux dmem cgroup. A capped half-GPU pod against the whole GPU, with NVIDIA's gpu-fractioning on an RTX A6000 as the reference.
