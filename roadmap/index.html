Roadmap

What is built, what comes next

Open Inference Fabric puts both GPU vendors behind one scheduler, one serving stack, one benchmark tool and one set of dashboards, installed with one command and removed just as cleanly. This page shows what is built, what is being proven now and what comes next.

Done In progress Up next Later

Status as of 15 November 2026, taken from the project's task list. Every "done" item passed its own test on real GPUs: a lab of five virtual machines (three control-plane nodes, one NVIDIA RTX A6000 worker, one AMD Radeon PRO W7900 worker), and now a single server with both GPUs.

Source, install guides and the full task list: github.com/openinferencefabric/oif. Contributions to the projects OIF builds on: upstream tracker. Home.
