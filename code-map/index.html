Reading it

  • Each colour is a cluster: installer stages, Run:ai patches, AMD GPU fractions, the vendor pool webhook, oif bench and so on.
  • Links read from the source (imports, calls, citations) are solid; links inferred from meaning are marked as inferred.
  • Lab IP addresses, host names and credentials are not in the map.
